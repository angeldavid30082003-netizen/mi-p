## Ejecutar en local

Descarga o clona este repositorio y abre `index.html` en un navegador.

## Publicar con GitHub Pages

1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta que contiene `index.html`.
4. Pulsa **Save**. GitHub mostrará el enlace público cuando termine la publicación.
